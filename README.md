# Prédio com Luzes Dinâmicas

Este é um projeto web que exibe um prédio com janelas que mudam de estado de acordo com o horário do dia.

## Funcionalidades

- Exibe um prédio com 9 janelas em uma grade 3x3
- As janelas ficam apagadas antes das 18:00
- As janelas ficam acesas depois das 18:00
- Mensagem "Bom dia" antes das 18:00
- Mensagem "Boa noite" depois das 18:00
- Atualização automática a cada minuto
- Transições suaves nas mudanças de estado das luzes

## Como usar

1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Observe as mudanças nas janelas de acordo com o horário do dia

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
